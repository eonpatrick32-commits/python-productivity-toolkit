## Quick Start

```bash
# Organize your downloads by file type
python toolkit.py files organize --dir ~/Downloads

# Convert CSV to JSON
python toolkit.py data csv2json --input data.csv --output data.json

# Extract text from a PDF
python toolkit.py pdf text --input document.pdf

# Batch resize images to 800px width
python toolkit.py image resize --dir ./photos --width 800

# Parse a URL into components
python toolkit.py web url-parse --url "https://example.com/path?key=val"
```
